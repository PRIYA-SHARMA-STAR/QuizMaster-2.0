# 🎮 QuizMaster 2.0 — Cosmic Neon Edition

A colorful, interactive quiz application built using HTML, CSS, and JavaScript, featuring a cosmic-inspired purple and blue interface.

## ✨ Features

- **Multiple Categories:** HTML, CSS, and JavaScript.
- **Difficulty Levels:** Easy, Medium, and Hard.
- **Timed Quizzes:** Answer questions within the time limit.
- **Instant Feedback:** See whether your answer is correct, with explanations.
- **Score Tracking:** View your quiz results and review answers.
- **Achievements:** Unlock badges as you progress.
- **Streak Tracking:** Track consecutive correct answers.
- **Sound Effects:** Audio feedback with a mute option.
- **Keyboard Shortcuts:** Use keyboard controls while playing.
- **Progress Dashboard:** View quiz statistics and recent attempts.
- **Personal Best:** Save your best performance in the browser.

## 🛠️ Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- Browser Local Storage

## 🚀 How to Run Locally

1. Clone or download this repository.
2. Keep `index.html`, `style.css`, and `script.js` in the same folder.
3. Open `index.html` in your browser, or use VS Code Live Server.
4. Select your preferred category and difficulty, then start the quiz.

## 💾 Data Storage

Quiz statistics, achievements, and personal progress are stored locally in the browser using Local Storage.
